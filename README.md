# No-Limit_PDF — versión definitiva

Esta versión incrusta los logos directamente dentro de `app.py`, por lo que no depende de la carpeta `assets/` ni de rutas relativas.

## Archivos requeridos

- `app.py`
- `requirements.txt`
- `packages.txt`

## Despliegue en Streamlit Cloud

1. Sube estos tres archivos a GitHub.
2. En Streamlit Cloud usa `app.py` como Main file path.
3. Haz Reboot/Redeploy.

## Características

- Interfaz minimalista blanco/negro.
- Tipografía Ubuntu.
- Traducción automática según navegador: español, portugués e inglés.
- Selector manual ES/PT/EN.
- Sube `.rar`, extrae PDFs, une y descarga el PDF final.
